# Лабораторная работа №6. Лемматизация и векторизация текстов

**Выполнил(а):** Иванов Артём Иванович 
**Группа:** ЕТ-216

## Описание работы
В рамках лабораторной работы выполнена предобработка корпуса из 25 русскоязычных отзывов о фильмах, включающая очистку текста от шума и морфологическую лемматизацию. Проведено сравнение различных способов векторизации: мешка слов (Bag of Words) с учётом N-грамм и взвешивания TF-IDF. Выполнен разведочный анализ корпуса: оценено распределение длин текстов, выявлены наиболее частотные леммы и рассчитано косинусное сходство между отзывами.

## Установка и запуск

1. Клонируйте репозиторий и перейдите в папку с лабораторной работой:
   ```bash
   git clone https://github.com/Art207141/Labs_sbor_analyz
   cd ./lab6
   ```

2. Установите необходимые зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Запустите Jupyter Notebook и откройте файл с решением:
   ```bash
   jupyter notebook notebook.ipynb
   ```
