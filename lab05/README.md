# Лабораторная работа 05
## Предобработка данных для ML и основы аналитики
**ФИО:** Иванов Артём Иванович
**Группа:** ЕТ-216

## Содержание
В работе выполнены:
- формулировка SMART-цели и построение MECE-декомпозиции;
- определение типов систематических смещений выборки;
- классификация признаков и поиск выбросов;
- сравнение скейлеров (`MinMaxScaler`, `StandardScaler`, `RobustScaler`);
- кодирование категорий (`OneHotEncoder`, `OrdinalEncoder`, `LabelEncoder`, Frequency);
- сборка единого конвейера препроцессинга в `ColumnTransformer` без утечки данных;
- построение простой случайной и стратифицированной выборок, оценка влияния размера выборки.
